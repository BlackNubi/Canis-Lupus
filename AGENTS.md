- The `main` branch of `BlackNubi/Canis-Lupus` is the active source of truth.
- For user-requested work in this project, make changes directly on GitHub `main` through the connected GitHub integration whenever available. Do not leave completed work only in a local or offline worktree.
- The user has authorized routine direct commits to this repository without per-change approval.

It does not authorize destructive history rewrites, deleting unrelated data, changing account or repository security/access/billing settings, or writing to other repositories; obtain approval for those actions.
